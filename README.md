# Sales Performance Analysis Dashboard

An interactive sales performance dashboard built using Power BI and MySQL.

## Dashboard Preview

![Sales Performance Dashboard](Sales-Performance-Dashboard.png)

## Tools & Technologies

- Power BI
- MySQL
- SQL
- DAX

## Project Overview

This project analyzes sales data to understand overall sales performance, profitability, product performance, category performance, regional performance, and monthly sales trends.

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Profit by Category
- Sales by Product
- Category and Region filters
